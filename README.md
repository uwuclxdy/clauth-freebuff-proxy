# clauth-freebuff-proxy

A clauth proxy for freebuff.com's free tier, built on `clauth-proxy-core`. Speaks the freebuff CLI's wire (sessions, agent runs, openai-shaped chat) and serves the clauth proxy contract v1.

> unofficial: freebuff's upstream says direct API use may get accounts banned. the deepseek and minimax-m3 model APIs train on your data. use at your own risk.
